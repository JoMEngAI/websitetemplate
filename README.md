# Joseph Mendoza — Resume Website

Personal resume website for the SWE 325/525 Career-Fair Resume Website
assignment. Static HTML, CSS, and JavaScript, published with GitHub Pages.

## Structure

- `index.html` — single-page site (About, Experience, Projects, Skills,
  Education, Resume, Contact)
- `assets/css/style.css` — site styles (navy/teal palette)
- `assets/js/main.js` — mobile menu and active-section highlighting
- `assets/img/favicon.svg` — site icon
- `content-plan.md`, `ai-log.md`, `evidence/` — assignment documentation

All asset paths are relative so the site works under a GitHub Pages
repository subpath.
